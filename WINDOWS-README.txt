Survey Studio / 논문 분석실 (Windows x64)

1. ZIP 파일 전체를 압축 해제하세요.
2. SurveyStudio.exe를 더블클릭하세요. Python 설치는 필요하지 않습니다.
3. 첫 실행은 포함된 실행 환경을 풀기 때문에 시간이 걸릴 수 있습니다.
4. 브라우저가 자동으로 열립니다. 열리지 않으면 콘솔에 표시된 주소를 복사하세요.
5. 검은 콘솔 창은 사용 중 열어 두고, 종료할 때 닫으세요.
6. 페이지를 닫기 전에 입력 CSV와 분석 리포트를 저장하세요. 자동 영구 저장은 없습니다.

지원: 사진 원본 확인, 직접 입력/CSV, 역채점, 기술통계, Cronbach alpha,
Pearson 상관, HTML 리포트 다운로드.

OCR은 별도 Tesseract 엔진이 설치된 경우에만 동작합니다.
EXE에는 Tesseract를 포함하지 않습니다. 설치하지 않아도 직접 입력과 통계 분석은 가능합니다.
한국어·필기·체크박스 응답 자동 판독은 지원하지 않습니다.
SPSS/AMOS, 요인분석, 구조방정식 및 매개효과 분석을 실행하지 않습니다.

이 실행 파일은 코드 서명되지 않았습니다. Windows에서 발행자 미확인 알림이 나타날 수 있습니다.
다운로드 출처와 동봉한 SHA256SUMS.txt를 확인하세요. 보안 기능을 끄지 마세요.

Windows x64 전용입니다. macOS 및 Windows ARM 네이티브 빌드는 포함되지 않습니다.
