# 논문 분석실

사진 확인 → 응답 입력/CSV 가져오기 → 척도 설정 → 검토 확인 → 통계 분석 → 독립 HTML 리포트 다운로드를 지원하는 로컬 Web GUI입니다.

## 실행

### Windows: Python 설치 없이 실행

[Windows EXE 빌드 페이지](https://github.com/kdesign1559-kkor/ky/actions/workflows/windows-exe.yml)에서 최신 성공한 실행을 열고 **Artifacts → SurveyStudio-Windows-x64**를 다운로드하세요. GitHub 로그인이 필요하며, 빌드가 완료되어야 나타납니다.

ZIP을 압축 해제한 뒤 `SurveyStudio.exe`를 더블클릭하면 브라우저가 자동으로 열립니다. 사용하는 동안 콘솔 창을 열어 두세요. 종료하려면 콘솔 창을 닫습니다. Python과 분석 라이브러리는 EXE 안에 포함됩니다. OCR 엔진 Tesseract는 포함하지 않으므로 OCR 없이 사진을 대조하여 입력하거나 CSV를 가져올 수 있습니다.

EXE는 Windows x64용이며 코드 서명되지 않았습니다. 함께 제공하는 `SHA256SUMS.txt`로 파일 무결성을 확인할 수 있습니다. 빌드는 Windows에서 실제 EXE를 실행하여 화면 파일과 통계 API를 검증한 뒤에만 아티팩트를 업로드하도록 설정되어 있습니다. 빌드 실패 또는 실행 전 상태를 완료된 EXE로 취급하지 마세요.

### 개발자 실행

Python 3.12 권장. `/workspace/ky`에서:

```sh
python -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app.py --host 127.0.0.1 --port 8000
```

브라우저에서 실행한 컴퓨터의 포트 8000으로 접속합니다. 현재 클라우드에서는 기본 Python에 필요한 패키지가 설치되어 있어 `python app.py`로 실행 가능합니다. 외부 접속은 해당 환경의 포트 전달 기능이 필요합니다. 공개 배포용 인증/접근통제는 구현되어 있지 않으므로 민감한 설문 데이터를 공개 서버에 올리지 마세요.

## 사용

1. 연구 제목, 척도 범위와 척도별 문항 열 이름 및 역문항을 설정합니다.
2. 사진을 선택하고 각 응답을 원본과 대조해 CSV 입력란에 입력합니다. 응답자 한 명당 한 행입니다. UTF-8 CSV 가져오기도 지원합니다. 결측은 빈칸입니다.
3. 사진 OCR은 선택 사항입니다. 시스템 Tesseract와 `eng` 언어 데이터가 필요합니다(현재 환경에 설치됨). 영문/숫자 텍스트 참고용이며, 한국어·체크박스·손글씨의 자동 응답 판독 및 매핑을 지원하지 않습니다.
4. 검토 확인 후 분석합니다. 가상 시연 데이터는 항상 가상 표시를 유지합니다.
5. CSV, 결과 JSON, HTML 리포트를 내려받습니다. HTML은 오프라인으로 열 수 있고 브라우저 인쇄로 PDF 저장이 가능합니다.

## 분석 범위

- 척도별 완전사례의 문항 평균, 표본 표준편차, 비표준화 Cronbach α.
- 척도점수 쌍별 완전사례의 양측 Pearson 상관검정. 다중검정 보정 없음.
- 범위 밖 값, 비정수, 중복 헤더/척도/문항 배정 등 검증. 역채점 및 결측 처리 기록.
- 입력 CSV 해시, 패키지 버전, 시각을 리포트에 기록.

SPSS/AMOS 자체 실행, EFA/CFA/SEM, 매개효과, 실제 논문 인용문헌 자동 생성은 지원하지 않습니다. 통계 결과만으로 논문 게재 적합성, 척도 타당성, 인과관계 또는 설계 안전성을 보증하지 않습니다. 자동 서술은 연구자 검토를 거쳐 사용하세요.

## 개인정보와 저장

사진 선택 시 브라우저에 표시하며 OCR 실행 시에만 서버로 전송합니다. 서버는 OCR을 임시 디렉터리에서 처리 후 삭제하며 응답을 영구 저장하지 않습니다. 외부 AI API는 사용하지 않습니다. 페이지를 닫으면 입력 내용이 사라집니다. 사본을 내려받아 안전한 곳에 보관하고 사진의 이름·서명·연락처는 업로드 전에 가리세요.
