논문 분석실

설문지 사진 → 응답 검토 → 실제 데이터 분석 → HTML 리포트

실제 데이터로 계산하는 연구 보조 도구입니다. 사진 OCR은 응답 자동 확정 기능이 아닙니다. 개인정보를 가린 사진을 사용하고, 원본 대조 후 분석하세요. SPSS·AMOS 실행 및 확인적 요인분석·구조방정식은 현재 지원하지 않습니다.

01 · 연구 및 척도 설정

문항 구성과 역채점 여부는 실제 설문 및 척도 개발 근거에 맞게 설정하세요. 역채점 = 최솟값 + 최댓값 − 응답값.

02 · 사진 확인과 응답 입력

사진을 선택하면 여기에서 원본을 확인할 수 있습니다.

영문·숫자 텍스트 추출만 지원합니다. 한국어·필기·선택 표시의 판독과 열 매핑은 직접 수행하세요. HEIC 등 읽을 수 없는 사진은 PNG/JPEG로 변환하세요.

한 행 = 응답자 1명. 결측은 빈칸으로 두세요. 문항에는 설정한 범위의 정수만 입력합니다. 사진 속 응답을 대조하며 직접 입력하거나 CSV를 불러오세요.




사진은 선택 시 브라우저에서 표시되고, OCR 실행 시에만 이 서버로 전송됩니다. 업로드 및 응답은 서버 디스크에 저장하지 않습니다. 입력은 페이지를 닫으면 사라지므로 CSV와 리포트를 내려받으세요. 공용 인터넷 공개용 인증 기능은 없습니다.
